## ✨ Özellikler

| | |
|---|---|
| 🔄 **Gerçek Zamanlı Çeviri** | Günümüz Türkçesindeki kelimeleri anında Göktürkçeye çevirir. Sözlükte yoksa harf harf (kalın/ince ünlü uyumuna göre) dönüştürür. |
| 🗿 **3D İnteraktif Müze** | React Three Fiber kullanılarak oluşturulmuş 3 boyutlu anıt üzerinde yazıları sergiler, döndürme ve inceleme imkanı sunar. |
| 📖 **Akıllı Corpus Mimarisi** | Çevrilen kelimeler Orhun Yazıtları'nda geçiyorsa, orijinal satırını, okunuşunu ve günümüz çevirisini kullanıcıya sunar. |
| 🖼️ **Görsel Olarak İndirme** | Kullanıcıların kendi çevirilerini taş/parşömen desenli arka planlarla yüksek çözünürlüklü PNG olarak indirmesini sağlar. |
| 🖋️ **Kusursuz Tipografi** | Google Noto Sans Old Turkic fontu kullanılarak tüm cihazlarda sorunsuz render edilir. |

## 🚀 Kurulum ve Çalıştırma

Projeyi lokalinizde çalıştırmak için aşağıdaki adımları izleyebilirsiniz:

```bash
# Repoyu klonlayın
git clone https://github.com/KULLANICI_ADINIZ/digital-gokturk.git

# Dizin içerisine girin
cd digital-gokturk

# Bağımlılıkları yükleyin
npm install

# Geliştirme sunucusunu başlatın
npm run dev
```
Ardından tarayıcınızda `http://localhost:3000` adresine giderek platformu görüntüleyebilirsiniz.
